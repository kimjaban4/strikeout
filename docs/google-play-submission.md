## 2. 기본 스토어 등록정보

### 앱 이름

마운드 심리전

### 짧은 설명

타자의 노림수를 읽고 구종과 코스를 설계하는 오프라인 야구 심리전 게임

### 자세한 설명

마운드 위에서 타자의 생각을 읽고 한 공씩 승부를 설계하세요.

마운드 심리전은 타자가 노리는 공과 코스를 추리하고, 구종·코스·릴리스 타이밍을 조합해 아웃을 잡는 오프라인 싱글 플레이 야구 게임입니다. 단순히 능력치가 높은 공을 반복하는 대신 앞선 승부기록과 타자의 반응을 읽어 다음 공을 결정해야 합니다.

주요 특징

- 빠른 공, 변화구, 느린 공을 타자의 노림수에 맞춰 배합
- 스트라이크존 코스와 릴리스 타이밍을 직접 선택
- 타자의 반응과 승부기록을 다음 공의 단서로 활용
- 좌투수·우투수와 좌타자·우타자의 상성 및 코스 차이 반영
- 4개 GAME, 12개 STAGE로 이어지는 한 번의 RUN
- 스테이지 보상과 덕아웃 작전으로 투구 운영 강화
- 클럽하우스에서 CP 한도에 맞춰 장비 구매 및 장착
- 광고, 계정, 인앱 결제 없이 오프라인 플레이

한 타자 한 타자에게 어떤 공을 보여주고 무엇을 숨길지 판단하세요. 같은 구종과 코스를 반복하면 타자가 투수의 의도를 읽기 시작합니다. 반대로 앞선 공을 미끼로 사용하면 결정구의 위력을 더 크게 만들 수 있습니다.

모든 진행 정보와 설정은 이용자의 기기에만 저장됩니다.

### 출시 노트

첫 출시
- 투수 선택과 12스테이지 RUN
- 구종·코스·릴리스 타이밍 투구 시스템
- 타자 노림수와 승부기록
- 스테이지 보상, 덕아웃 작전, 클럽하우스 장비
- 좌우 투타 상성과 오프라인 이어하기

## 3. 그래픽 자료

| 자료 | 필수 규격 | 상태 |
| --- | --- | --- |
| 스토어 아이콘 | 512×512, 32비트 PNG, 알파 허용, 1MB 이하 | `store-assets/google-play/icon-512.png` 검증 완료 |
| 기능 그래픽 | 1024×500, 24비트 PNG 또는 JPG, 알파 없음 | `store-assets/google-play/feature-graphic-1024x500.png` 검증 완료 |
| 휴대전화 스크린샷 | PNG/JPG, 각 변 320~3840px, 긴 변은 짧은 변의 2배 이하 | 1080×1920 실제 게임 화면 4장 검증 완료 |

게임 추천 영역 노출을 고려해 실제 앱 화면의 1080×1920 세로 스크린샷 4장을 준비합니다.

### 스크린샷 순서와 대체 텍스트

1. 투구 화면 — `타자의 노림수를 읽으며 구종과 스트라이크존 코스를 선택하는 투구 화면`
2. 승부기록 — `타자의 스윙 반응과 이전 투구 결과를 확인하는 승부기록 화면`
3. 스테이지 보상 — `RUN 운영을 강화할 보상 카드 세 장 중 하나를 선택하는 화면`
4. 클럽하우스 — `CP 한도 안에서 야구 장비를 구매하고 장착하는 클럽하우스 화면`

기능 그래픽 대체 텍스트: `야구공과 조준점을 중심으로 투수와 타자의 심리전을 표현한 마운드 심리전 표지`

기기 테두리, 손가락, 다운로드 문구, 순위·가격 표현은 넣지 않습니다.
